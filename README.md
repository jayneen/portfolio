## Tech Stack

- **Frontend:** React, TypeScript, Material UI (MUI)
- **Routing:** React Router

## Features

- Responsive portfolio layout
- Project cards with detailed project descriptions
- Individual project pages with links to live demos and source code
- Professional experience and about sections
- Contact links for professional networking and collaboration

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/jayneen/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal. By default, Vite uses:

   `http://localhost:5173`

## Project Structure

The application is organized into reusable React components and separate project data.

- **Components:** Reusable UI sections and elements
- **Pages:** Portfolio homepage and individual project detail pages
- **Data:** Project information used to render project cards and detail pages
- **Theme:** Shared Material UI styling

## Usage

Visitors can explore my software engineering projects, read detailed project descriptions, and follow links to live demos or source code repositories.

The portfolio also provides information about my professional experience and links to my contact information and professional profiles.
